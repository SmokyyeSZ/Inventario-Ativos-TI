## 🛡️ Visão Geral — JESTER RISK

O **JESTER RISK** (*Jester Security Intelligence — Risk Propagation Model*) é uma plataforma web completa voltada a equipes de **SOC (Security Operations Center)**, Infraestrutura e Cibersegurança. O sistema unifica o gerenciamento de ativos computacionais com um **motor algébrico espectral** capaz de quantificar não apenas o risco isolado de uma máquina vulnerável, mas **como esse risco se propaga lateralmente pela topologia da rede corporativa**.

Ao cadastrar servidores, bancos de dados, endpoints em nuvem, gateways, firewalls e estações de trabalho, o analista modela as conexões reais entre os ativos (portas, protocolos, direcionalidade e peso de contágio) e vincula vulnerabilidades consultadas em tempo real na base oficial do **NIST (National Vulnerability Database — API v2.0)**. A cada alteração na rede ou no estado de uma CVE, o backend recalcula instantaneamente o sistema linear $(I - A) \cdot x = b$, atualizando os índices de criticidade e o mapa topológico interativo.

## ✨ Principais Funcionalidades

- **🔐 Autenticação Segura & Escopo por Responsável (JWT):**
  - Login via **SimpleJWT** (`access` e `refresh` tokens) com interceptor Axios no frontend para renovação transparente de sessão sem desconexão em *reload* (`F5`).
  - Vínculo direto de ativos ao usuário responsável (`User`), preparando a governança de superfície de ataque por analista/equipe.
- **🏭 Inventário Polimórfico de Ativos (POO + Factory Pattern):**
  - Especialização de ativos via herança multi-tabela no Django ORM (`Servidor`, `Database`, `CloudEndpoint`, `Gateway`, `Firewall`, `Workstation`), instanciados dinamicamente pela fábrica `Factory_equipamento`.
  - Conversão automática de convenções `snake_case` (Python/Django) $\leftrightarrow$ `camelCase` (TypeScript/React) na camada REST.
- **🧬 Gestão Híbrida de Vulnerabilidades (NIST NVD API v2.0):**
  - Consulta automatizada pelo código CVE (ex.: `CVE-2021-44228`) extraindo descrição oficial, **CVSS v3.1 / v2.0 Base Score**, severidade e vetor de ataque (`NETWORK`, `ADJACENT`, `LOCAL`).
  - **Fallback Resiliente:** Em ambientes isolados (sem internet), *timeout* da API externa ou CVEs internas/zero-day ainda não publicadas, o cadastro prossegue de forma 100% manual sem interromper a operação.
- **🕸️ Topologia Interativa & Simulação de Movimento Lateral:**
  - Grafo interativo em SVG com *zoom*, *pan*, inspeção de nós, criação de enlaces direcionados (`Outbound`, `Inbound`, `Bidirecional`) e bloqueio rápido de arestas críticas (`Ativa` / `Monitorada` / `Bloqueada`).
  - **Modo Simulação de Contágio:** Visualiza rotas de propagação lateral e impacto em cascata a partir de ativos comprometidos, além de diagnóstico rápido via *Ping Terminal* simulado.
- **📊 Telemetria Espectral no Dashboard SOC:**
  - Cálculo em tempo real do **Raio Espectral ($\lambda_{\max}$)**, **Densidade da Matriz de Adjacência ($\rho$)**, **Mapa de Calor ($A_{ij}$)** dos vetores de contágio e distribuição global de severidade de CVEs.

## 📐 Motor Matemático de Propagação Espectral

Implementado em `inventario/motor_matematico.py` com **NumPy**, o motor modela a infraestrutura de TI como um grafo direcionado ponderado $G = (V, E)$, onde $|V| = n$ ativos.

### 1. Vetor de Risco Intrínseco ($b \in \mathbb{R}^n$)
Para cada ativo $i \in \{1, \dots, n\}$, soma-se a pontuação CVSS de todas as vulnerabilidades **ativas** (não mitigadas) multiplicada pelo fator polimórfico de exposição da sua subclasse $f_{\text{exp}}(i)$:

$$
b_i = \left( \sum_{v \in \text{CVEs}(i)} \text{CVSS}_v \right) \cdot f_{\text{exp}}(i)
$$

### 2. Matriz de Adjacência e Propagação ($A \in \mathbb{R}^{n \times n}$)
Cada conexão ativa (`status != "Bloqueada"`) entre dois ativos possui um peso de propagação $w \in [0, 1]$:
- **`Outbound`** ($i \to j$): $A_{ij} = w$
- **`Inbound`** ($j \to i$): $A_{ji} = w$
- **`Bidirecional`** ($i \leftrightarrow j$): $A_{ij} = A_{ji} = w$

### 3. Resolução do Risco Propagado ($x \in \mathbb{R}^n$)
O risco efetivo $x_i$ de um ativo incorpora tanto suas falhas locais ($b_i$) quanto o risco herdado recursivamente dos seus vizinhos na rede ($A \cdot x$), formando a série de Neumann convergida no sistema linear:

$$
x = b + A x \implies (I - A) \cdot x = b
$$

O backend resolve o sistema exato via decomposição LU em `numpy.linalg.solve(np.eye(n) - A, b)`. Caso a topologia gere uma matriz singular ($\det(I - A) = 0$), o motor aciona automaticamente um *fallback* seguro preservando o vetor intrínseco $b$.

### 4. Métricas Espectrais de Governança ($\lambda_{\max}$ e $\rho$)
Para avaliar a resiliência estrutural da rede como um todo, o endpoint `/api/metrics/` extrai os autovalores de $A$:

$$
\lambda_{\max}(A) = \max_{1 \le k \le n} |\lambda_k|, \qquad \rho(A) = \frac{\text{nnz}(A)}{n^2}
$$

> [!IMPORTANT]
> Quando $\lambda_{\max}(A) < 1$, a propagação de risco na rede converge matematicamente de forma estável. Valores próximos ou superiores a $1$ alertam o SOC sobre ciclos densos de movimento lateral que exigem segmentação imediata (bloqueio de arestas ou *firewalls* internos).

## 🔌 Principais Endpoints da API REST

Todos os endpoints (exceto obtenção/renovação de token) exigem cabeçalho `Authorization: Bearer <access_token>`.

| Método | Endpoint | Descrição |
| :---: | :--- | :--- |
| `POST` | `/api/token/` | Autentica credenciais e retorna o par de tokens JWT (`access` e `refresh`). |
| `POST` | `/api/token/refresh/` | Renova o `access` token expirado a partir de um `refresh` token válido. |
| `GET` | `/api/metrics/` | Retorna raio espectral ($\lambda_{\max}$), densidade ($\rho$), matriz de calor $A_{ij}$ e contadores CVSS. |
| `GET` `POST` | `/api/equipamentos/` | Lista os ativos sob responsabilidade do usuário ou instancia um novo ativo via `Factory_equipamento`. |
| `GET` `PATCH` `DELETE` | `/api/equipamentos/<uuid>/` | Consulta detalhes completos, atualiza atributos ou remove um ativo recalculando a rede. |
| `POST` | `/api/equipamentos/<uuid>/cves/` | Vincula uma CVE consultando automaticamente a NIST NVD API v2.0 (com *fallback* manual) e recalcula $(I - A)x = b$. |
| `DELETE` | `/api/equipamentos/<uuid>/cves/<cve_code>/` | Remove uma vulnerabilidade do ativo e recalcula o risco propagado da malha. |
| `POST` | `/api/equipamentos/<uuid>/connections/` | Cria um enlace de rede (`Outbound`, `Inbound` ou `Bidirecional`) com peso de propagação. |
| `PATCH` `DELETE` | `/api/equipamentos/<uuid>/connections/<id>/` | Altera o status da conexão (ex.: isolar/bloquear rota lateral) ou exclui a aresta. |
| `POST` | `/api/equipamentos/<uuid>/ping/` | Executa diagnóstico de conectividade, latência e portas abertas a partir das conexões ativas. |

def pytest_runtest_logreport(report):
    global _ultimo_modulo
    if report.when != "call":
        return

    nome_teste = report.nodeid.split("::")[-1]
    info = DESCRICAO_TESTES.get(nome_teste)
    _resultados.append((nome_teste, report.outcome, report.duration))

    if info:
        modulo, titulo, explicacao = info
        if modulo != _ultimo_modulo:
            _ultimo_modulo = modulo
            print(f"\n  {C_YELLOW}{C_BOLD}[ {modulo} ]{C_RESET}")
            print(f"  {C_DIM}{'─' * 78}{C_RESET}")

        badge = (
            f"{C_GREEN}{C_BOLD}[ PASSOU ({report.duration * 1000:.0f}ms) ]{C_RESET}"
            if report.outcome == "passed"
            else f"{C_RED}{C_BOLD}[ FALHOU ]{C_RESET}"
        )
        print(f"  {badge} {C_WHITE}{C_BOLD}{titulo}{C_RESET}")
        print(f"     {C_DIM}↳ O que faz:{C_RESET} {C_WHITE}{explicacao}{C_RESET}")
    else:
        badge = f"{C_GREEN}[ PASSOU ]{C_RESET}" if report.outcome == "passed" else f"{C_RED}[ FALHOU ]{C_RESET}"
        print(f"  {badge} {nome_teste}")

#!/usr/bin/env python3
"""
Executor Multiplataforma de Testes — JESTER RISK (Windows & Linux)
Pode ser executado diretamente com:
    python testar_projeto.py
Redireciona automaticamente para o interpretador do venv (se existir)
e inicia a suíte completa do Pytest.
"""

import os
import sys
import subprocess
from pathlib import Path


def localizar_python_venv(raiz: Path) -> str:
    """Detecta automaticamente o Python do ambiente virtual no Windows ou Linux."""
    candidatos = [
        raiz / "venv" / "Scripts" / "python.exe",  # Windows
        raiz / ".venv" / "Scripts" / "python.exe", # Windows (.venv)
        raiz / "venv" / "bin" / "python",          # Linux / macOS
        raiz / ".venv" / "bin" / "python",         # Linux / macOS (.venv)
    ]
    for caminho in candidatos:
        if caminho.exists():
            return str(caminho)
    return sys.executable


def main() -> int:
    raiz = Path(__file__).resolve().parent
    os.chdir(raiz)

    python_exec = localizar_python_venv(raiz)
    args_extras = sys.argv[1:]

    comando = [python_exec, "-m", "pytest"] + args_extras
    resultado = subprocess.run(comando)
    return resultado.returncode


if __name__ == "__main__":
    raise SystemExit(main())

import { ApiConfigModal } from './components/ApiConfigModal';

export const App: React.FC = () => {
  const navigate = useNavigate();
  const location = useLocation();
  const isLoginPage = location.pathname === '/login';

  const getTabFromPath = (pathname: string): ActiveTab => {
    if (pathname === '/inventario') return 'inventory';
    if (pathname === '/equipamentos') return 'details';
    return 'dashboard';
  };

  const [activeTab, setActiveTab] = useState<ActiveTab>(() => getTabFromPath(location.pathname));
  const [metrics, setMetrics] = useState<RiskPropagationMetrics>(initialMetrics);
  const [assets, setAssets] = useState<Asset[]>([]);
  const [selectedAsset, setSelectedAsset] = useState<Asset | null>(null);
  const [propagationSpeed, setPropagationSpeed] = useState<number>(initialMetrics.propagationSpeed);
  const [apiUrl, setApiUrl] = useState<string>(
    import.meta.env.VITE_API_BASE_URL || (import.meta.env.PROD ? '/api' : 'http://localhost:8000/api')
  );
  const [isRefreshing, setIsRefreshing] = useState(false);
  const [errorMessage, setErrorMessage] = useState('');

  const [isEditModalOpen, setIsEditModalOpen] = useState(false);
  const [isLinkCveModalOpen, setIsLinkCveModalOpen] = useState(false);
  const [isConnectModalOpen, setIsConnectModalOpen] = useState(false);
  const [isAddAssetModalOpen, setIsAddAssetModalOpen] = useState(false);
  const [isApiConfigModalOpen, setIsApiConfigModalOpen] = useState(false);

  useEffect(() => {
    setActiveTab(getTabFromPath(location.pathname));
  }, [location.pathname]);

  useEffect(() => {
    loadData();
  }, []);

  const loadData = async (keepSelectedId?: string) => {
    const token = localStorage.getItem('accessToken');
    if (!token) {
      if (location.pathname !== '/login') {
        navigate('/login', { replace: true });
      }
      return;
    }

    setIsRefreshing(true);
    setErrorMessage('');
    try {
      const [fetchedMetrics, fetchedAssets] = await Promise.all([
        fetchDashboardMetrics(),
        fetchAssets(),
      ]);
      setMetrics(fetchedMetrics);
      setAssets(fetchedAssets);
      if (fetchedAssets.length > 0) {
        const targetId = keepSelectedId ?? selectedAsset?.id;
        const found = fetchedAssets.find((a) => String(a.id) === String(targetId));
        setSelectedAsset(found || fetchedAssets[0]);
      } else {
        setSelectedAsset(null);
      }
    } catch (err) {
      if (!localStorage.getItem('accessToken') || (axios.isAxiosError(err) && err.response?.status === 401)) {
        localStorage.removeItem('accessToken');
        localStorage.removeItem('refreshToken');
        setErrorMessage('');
        navigate('/login', { replace: true });
      } else {
        setErrorMessage('Não foi possível sincronizar os dados com o servidor Django.');
      }
    } finally {
      setIsRefreshing(false);
    }
  };

  const handleSelectAsset = (asset: Asset) => {
    setSelectedAsset(asset);
    setActiveTab('details');
    navigate('/equipamentos');
  };

  const handleSaveAsset = async (updatedFields: Partial<Asset>) => {
    if (!selectedAsset) return;
    await updateAssetOnServer(selectedAsset.id, updatedFields);
    await loadData(selectedAsset.id);
  };

  const handleDeleteAsset = async (asset: Asset) => {
    if (!window.confirm(`Tem certeza que deseja apagar o ativo "${asset.nome}"?`)) return;
    await deleteAssetOnServer(asset.id);
    await loadData();
  };

  const handleLinkCve = async (cve: Partial<CveItem> & { id: string; modo?: 'api' | 'manual' }) => {
    if (!selectedAsset) return;
    await linkCveToAssetOnServer(selectedAsset.id, cve);
    await loadData(selectedAsset.id);
  };

  const handleUnlinkCve = async (cveId: string) => {
    if (!selectedAsset) return;
    await unlinkCveOnServer(selectedAsset.id, cveId);
    await loadData(selectedAsset.id);
  };

  const handleAddConnection = async (conn: NetworkConnection) => {
    if (!selectedAsset) return;
    await addConnectionOnServer(selectedAsset.id, conn);
    await loadData(selectedAsset.id);
  };

  const handleUpdateConnection = async (connId: string, updated: Partial<NetworkConnection>) => {
    if (!selectedAsset) return;
    await updateConnectionOnServer(selectedAsset.id, connId, updated);
    await loadData(selectedAsset.id);
  };

  const handleDeleteConnection = async (connId: string) => {
    if (!selectedAsset) return;
    await deleteConnectionOnServer(selectedAsset.id, connId);
    await loadData(selectedAsset.id);
  };

  const handleAddAsset = async (newAsset: Partial<Asset>) => {
    const created = await createAssetOnServer(newAsset);
    await loadData(created.id);
  };

  const handleMenuClick = async (tab: ActiveTab) => {
    if (tab === 'dashboard') {
      setActiveTab('dashboard');
      navigate('/dashboard');
    }
    if (tab === 'inventory') {
      setActiveTab('inventory');
      navigate('/inventario');
    }
    if (tab === 'details') {
      setActiveTab('details');
      navigate('/equipamentos');
    }
  };

  return (
    <div className="min-h-screen bg-[#070b12] text-slate-100 flex flex-col font-sans selection:bg-rose-500/30 selection:text-rose-200">
      {!isLoginPage && (
        <Navbar
          activeTab={activeTab}
          onTabChange={handleMenuClick}
          onOpenApiConfig={() => setIsApiConfigModalOpen(true)}
          onRefreshData={() => loadData()}
          isRefreshing={isRefreshing}
          selectedAssetNome={selectedAsset?.nome}
        />
      )}

      <main className={isLoginPage ? 'flex-1 w-full' : 'flex-1 max-w-[1720px] w-full mx-auto p-4 lg:p-8'}>
        {errorMessage && !isLoginPage ? (
          <div className="flex flex-col items-center justify-center p-12 border border-rose-500/40 bg-[#0b101b] rounded-xl shadow-[0_0_30px_rgba(239,68,68,0.15)] text-center min-h-[50vh]">
            <div className="w-16 h-16 bg-rose-500/20 rounded-full flex items-center justify-center mb-4 border border-rose-500/50">
              <span className="text-rose-500 text-3xl">⚠️</span>
            </div>
            <h2 className="text-xl font-bold font-mono text-white mb-2">Conexão com o Servidor Perdida</h2>
            <p className="text-sm font-mono text-rose-400 mb-6">{errorMessage}</p>
            <button
              onClick={() => loadData()}
              className="px-6 py-2 bg-rose-600 hover:bg-rose-500 text-white font-semibold font-mono text-xs rounded-lg transition-colors cursor-pointer"
            >
              Tentar Reconectar
            </button>
          </div>
        ) : (
          <Routes>
            <Route path="/" element={<Navigate to="/dashboard" replace />} />

            <Route
              path="/dashboard"
              element={
                <DashboardView
                  metrics={metrics}
                  assets={assets}
                  onSelectAsset={handleSelectAsset}
                  selectedAssetId={selectedAsset?.id}
                  propagationSpeed={propagationSpeed}
                  onPropagationSpeedChange={setPropagationSpeed}
                  onGoToInventory={() => handleMenuClick('inventory')}
                />
              }
            />

            <Route
              path="/inventario"
              element={
                <AssetInventoryTable
                  assets={assets}
                  onSelectAsset={handleSelectAsset}
                  onEditAsset={(asset) => {
                    setSelectedAsset(asset);
                    setIsEditModalOpen(true);
                  }}
                  onConnectAsset={(asset) => {
                    setSelectedAsset(asset);
                    setIsConnectModalOpen(true);
                  }}
                  onDeleteAsset={handleDeleteAsset}
                  onOpenAddModal={() => setIsAddAssetModalOpen(true)}
                />
              }
            />

            <Route
              path="/equipamentos"
              element={
                selectedAsset ? (
                  <EquipmentDetails
                    asset={selectedAsset}
                    allAssets={assets}
                    onSelectAnotherAsset={setSelectedAsset}
                    onOpenEdit={() => setIsEditModalOpen(true)}
                    onOpenLinkCve={() => setIsLinkCveModalOpen(true)}
                    onOpenConnect={() => setIsConnectModalOpen(true)}
                    onUnlinkCve={handleUnlinkCve}
                    onAddConnection={handleAddConnection}
                    onUpdateConnection={handleUpdateConnection}
                    onDeleteConnection={handleDeleteConnection}
                  />
                ) : (
                  <div className="p-8 text-center text-slate-500 font-mono mt-10">
                    Nenhum equipamento selecionado ou cadastrado no banco de dados.
                  </div>
                )
              }
            />

            <Route
              path="/login"
              element={<LoginView onLoginSuccess={() => loadData()} />}
            />

            <Route
              path="/terminal"
              element={
                <div>
                  <h1>Terminal em construção</h1>
                </div>
              }
            />
          </Routes>
        )}
      </main>

      {!isLoginPage && (
        <footer className="border-t border-slate-900 bg-[#05080e] px-4 lg:px-8 py-4 text-xs font-mono text-slate-500">
          <div className="max-w-[1720px] mx-auto flex flex-col sm:flex-row items-center justify-between gap-2">
            <div className="flex items-center gap-3">
              <span className="text-slate-400 font-semibold">JESTER SECURITY INTELLIGENCE</span>
              <span>·</span>
              <span>REST API Endpoint: {apiUrl}</span>
            </div>
            <div>
              <span>Modelo Espectral: Matriz Adjacente de Markov & Autovalor Máximo (λmax)</span>
            </div>
          </div>
        </footer>
      )}

      {selectedAsset && (
        <>
          {isEditModalOpen && (
            <EditAssetModal
              asset={selectedAsset}
              isOpen={isEditModalOpen}
              onClose={() => setIsEditModalOpen(false)}
              onSave={handleSaveAsset}
            />
          )}

          <LinkCveModal
            assetName={selectedAsset.nome}
            isOpen={isLinkCveModalOpen}
            onClose={() => setIsLinkCveModalOpen(false)}
            onLink={handleLinkCve}
          />

          <ConnectTerminalModal
            asset={selectedAsset}
            isOpen={isConnectModalOpen}
            onClose={() => setIsConnectModalOpen(false)}
          />
        </>
      )}

      <AddAssetModal
        isOpen={isAddAssetModalOpen}
        onClose={() => setIsAddAssetModalOpen(false)}
        onAdd={handleAddAsset}
      />

      <ApiConfigModal
        isOpen={isApiConfigModalOpen}
        onClose={() => setIsApiConfigModalOpen(false)}
        currentUrl={apiUrl}
        onSaveUrl={(newUrl) => {
          updateApiBaseUrl(newUrl);
          setApiUrl(newUrl);
        }}
      />
    </div>
  );
};

export default App;

import React, { useState } from 'react';
import axios from 'axios';
import { X, Server, Plus } from 'lucide-react';
import { Asset } from '../types';

interface AddAssetModalProps {
  isOpen: boolean;
  onClose: () => void;
  onAdd: (newAsset: Partial<Asset>) => Promise<void> | void;
}

export const AddAssetModal: React.FC<AddAssetModalProps> = ({ isOpen, onClose, onAdd }) => {
  const [nome, setNome] = useState('');
  const [departamento, setDepartamento] = useState('Infraestrutura Cloud');
  const [ip, setIp] = useState('10.100.');
  const [tipo, setTipo] = useState<Asset['tipo']>('Internal Server');
  const [responsavel, setResponsavel] = useState('');
  const [sistemaOperacional, setSistemaOperacional] = useState('Ubuntu Linux 24.04 LTS');
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [errorMsg, setErrorMsg] = useState('');

  if (!isOpen) return null;

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    if (!nome.trim() || !ip.trim()) return;

    setErrorMsg('');
    setIsSubmitting(true);

    const newAsset: Partial<Asset> = {
      nome: nome.trim().toUpperCase(),
      departamento: departamento.trim(),
      ip: ip.trim(),
      mac:
        '00:1A:2B:' +
        Math.floor(10 + Math.random() * 89) +
        ':' +
        Math.floor(10 + Math.random() * 89) +
        ':' +
        Math.floor(10 + Math.random() * 89),
      tipo,
      responsavel: responsavel.trim(),
      riscoFinal: 0.0,
      pesoPropagacao: 0.0,
      status: 'online',
      ultimoScan: 'Agora mesmo',
      sistemaOperacional: sistemaOperacional.trim(),
    };

    try {
      await onAdd(newAsset);
      setNome('');
      setResponsavel('');
      onClose();
    } catch (err) {
      if (axios.isAxiosError(err) && err.response?.data) {
        const data = err.response.data as Record<string, unknown>;
        const firstError = Object.values(data)[0];
        if (Array.isArray(firstError) && typeof firstError[0] === 'string') {
          setErrorMsg(firstError[0]);
        } else if (typeof firstError === 'string') {
          setErrorMsg(firstError);
        } else {
          setErrorMsg('Não foi possível salvar o ativo. Verifique os dados informados.');
        }
      } else {
        setErrorMsg('Não foi possível salvar o ativo. Verifique a conexão com a API.');
      }
    } finally {
      setIsSubmitting(false);
    }
  };

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/80 backdrop-blur-sm">
      <div className="relative w-full max-w-lg bg-[#0b101b] border border-cyan-500/30 rounded-xl shadow-[0_0_30px_rgba(6,182,212,0.2)] overflow-hidden">
        <div className="flex items-center justify-between px-6 py-4 border-b border-slate-800 bg-[#0d1424]">
          <div className="flex items-center gap-3">
            <Server className="w-5 h-5 text-cyan-400" />
            <h2 className="text-base font-semibold text-white tracking-wide">Cadastrar Novo Ativo</h2>
          </div>
          <button
            onClick={onClose}
            className="p-1.5 text-slate-400 hover:text-white rounded-lg hover:bg-slate-800 transition-colors"
          >
            <X className="w-5 h-5" />
          </button>
        </div>

        <form onSubmit={handleSubmit} className="p-6 space-y-4">
          {errorMsg && (
            <div className="p-3 rounded-lg bg-rose-950/60 border border-rose-500/40 text-xs font-mono text-rose-300">
              {errorMsg}
            </div>
          )}

          <div>
            <label className="block text-xs font-mono text-slate-400 mb-1.5">Nome do Ativo</label>
            <input
              type="text"
              required
              placeholder="Ex: PROD-API-03, AUTH-SRV"
              value={nome}
              onChange={(e) => setNome(e.target.value)}
              className="w-full px-3 py-2 bg-[#060911] border border-slate-700 rounded-lg text-sm text-slate-100 uppercase focus:outline-none focus:border-cyan-500"
            />
          </div>

          <div className="grid grid-cols-1 sm:grid-cols-2 gap-4">

interface ApiConfigModalProps {
  isOpen: boolean;
  onClose: () => void;
  currentUrl: string;
  onSaveUrl: (newUrl: string) => void;
}

export const ApiConfigModal: React.FC<ApiConfigModalProps> = ({ isOpen, onClose, currentUrl, onSaveUrl }) => {
  const [url, setUrl] = useState(currentUrl);
  const [status, setStatus] = useState<'idle' | 'testing' | 'success' | 'failed'>('idle');
  const [message, setMessage] = useState('');

  if (!isOpen) return null;

  const testConnection = async () => {
    setStatus('testing');
    setMessage('Verificando conexão com o endpoint Django...');
    try {
      const target = url.endsWith('/') ? url : `${url}/`;
      await axios.get(`${target}metrics/`, { timeout: 3000 });
      setStatus('success');
      setMessage('Conexão estabelecida com sucesso com o backend Python/Django!');
    } catch {
      setStatus('failed');
      setMessage('Não foi possível conectar a este endpoint no momento. O frontend continuará operando normalmente em modo de interface.');
    }
  };

  const handleSave = (e: React.FormEvent) => {
    e.preventDefault();
    onSaveUrl(url.trim());
    onClose();
  };

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/80 backdrop-blur-sm">
      <div className="relative w-full max-w-lg bg-[#0b101b] border border-blue-500/30 rounded-xl shadow-[0_0_30px_rgba(59,130,246,0.2)] overflow-hidden">
        <div className="flex items-center justify-between px-6 py-4 border-b border-slate-800 bg-[#0d1424]">
          <div className="flex items-center gap-3">
            <Network className="w-5 h-5 text-blue-400" />
            <h2 className="text-base font-semibold text-white tracking-wide">Configuração do Backend REST (Django)</h2>
          </div>
          <button
            onClick={onClose}
            className="p-1.5 text-slate-400 hover:text-white rounded-lg hover:bg-slate-800 transition-colors"
          >
            <X className="w-5 h-5" />
          </button>
        </div>

        <form onSubmit={handleSave} className="p-6 space-y-4">
          <div>
            <label className="block text-xs font-mono text-slate-400 mb-1.5">
              URL Base da API REST Python/Django
            </label>
            <input
              type="text"
              required
              value={url}
              onChange={(e) => setUrl(e.target.value)}
              placeholder="http://localhost:8000/api"
              className="w-full px-3 py-2 bg-[#060911] border border-slate-700 rounded-lg text-sm font-mono text-slate-100 focus:outline-none focus:border-blue-500"
            />
          </div>

          <div className="p-3.5 bg-[#060911] rounded-lg border border-slate-800 text-xs font-mono space-y-1.5 text-slate-400">
            <p className="text-slate-300 font-semibold">Rotas REST consumidas pelo frontend:</p>
            <p>• <span className="text-cyan-400">GET</span> /metrics/ - Métricas e matrizes de risco</p>
            <p>• <span className="text-cyan-400">GET/POST</span> /assets/ - Lista e criação de ativos</p>
            <p>• <span className="text-amber-400">POST/DEL</span> /assets/:id/cves/ - Vínculo de CVEs</p>
            <p>• <span className="text-rose-400">POST</span> /assets/:id/ping/ - Teste de conexão</p>
          </div>

          <div className="flex items-center gap-2">
            <button
              type="button"
              onClick={testConnection}
              disabled={status === 'testing'}
              className="flex items-center gap-2 px-3 py-1.5 text-xs font-mono text-blue-300 bg-blue-950/60 hover:bg-blue-900/60 border border-blue-800 rounded-lg transition-colors cursor-pointer"
            >
              <RefreshCw className={`w-3.5 h-3.5 ${status === 'testing' ? 'animate-spin' : ''}`} />
              Testar Conexão REST
            </button>
            {status === 'success' && (
              <span className="flex items-center gap-1.5 text-xs text-emerald-400 font-mono">
                <CheckCircle className="w-3.5 h-3.5" /> Online
              </span>

import React, { useState } from 'react';
import { ZoomIn, ZoomOut, RotateCcw, ShieldAlert, Cpu, Eye } from 'lucide-react';
import { Asset } from '../types';

interface NetworkTopologyGraphProps {
  assets: Asset[];
  onSelectAsset: (asset: Asset) => void;
  selectedAssetId?: string;
  propagationSpeed: number;
  onPropagationSpeedChange: (val: number) => void;
}

interface GraphNode {
  id: string;
  name: string;
  type: string;
  x: number;
  y: number;
  risk: number;
  status: string;
  tier: 'core' | 'hub' | 'leaf';
}

interface GraphLink {
  source: string;
  target: string;
  weight: number;
  direcao: 'Inbound' | 'Outbound' | 'Bidirecional';
  riskFlow: boolean;
}

export const NetworkTopologyGraph: React.FC<NetworkTopologyGraphProps> = ({
  assets,
  onSelectAsset,
  selectedAssetId,
  propagationSpeed,
  onPropagationSpeedChange,
}) => {
  const [zoom, setZoom] = useState(1);
  const [highlightedNode, setHighlightedNode] = useState<string | null>(null);
  const [searchQuery, setSearchQuery] = useState('');

  const centerX = 360;
  const centerY = 190;

  // Mapa rápido de vizinhos de cada ativo para posicionar nós conectados próximos entre si
  const neighborMap = new Map<string, Set<string>>();
  for (const a of assets) {
    const id = String(a.id);
    if (!neighborMap.has(id)) neighborMap.set(id, new Set());
    for (const c of a.conexoes || []) {
      if (c.status === 'Bloqueada') continue;
      const src = String(c.origemId ?? a.id);
      const dst = String(c.destinoId);
      if (!neighborMap.has(src)) neighborMap.set(src, new Set());
      if (!neighborMap.has(dst)) neighborMap.set(dst, new Set());
      neighborMap.get(src)!.add(dst);
      neighborMap.get(dst)!.add(src);
    }
  }

  const areConnected = (idA: string, idB: string) =>
    neighborMap.get(idA)?.has(idB) || neighborMap.get(idB)?.has(idA) || false;

  // Ordena ativos por relevância neural (risco final + grau de conexões)
  const rankedAssets = [...assets].sort((a, b) => {
    const degA = neighborMap.get(String(a.id))?.size ?? (a.conexoes?.length || 0);
    const degB = neighborMap.get(String(b.id))?.size ?? (b.conexoes?.length || 0);
    const scoreA = Number(a.riscoFinal ?? 0) * 2 + degA * 4;
    const scoreB = Number(b.riscoFinal ?? 0) * 2 + degB * 4;
    return scoreB - scoreA;
  });

  const nodeCoords = new Map<string, { x: number; y: number; tier: GraphNode['tier'] }>();

  if (rankedAssets.length > 0) {
    // 1. Nó Central (Core)
    const coreAsset = rankedAssets[0];
    nodeCoords.set(String(coreAsset.id), { x: centerX, y: centerY, tier: 'core' });

    // 2. Camada Intermediária (até 4 Sub-Hubs agrupados por afinidade em X simétrico)
    const hubAssets = rankedAssets.slice(1, 5);
    const leftHubSlots = [
      { x: 225, y: 120 },
      { x: 225, y: 260 },
    ];
    const rightHubSlots = [
      { x: 495, y: 120 },
      { x: 495, y: 260 },
    ];

    const leftHubs: Asset[] = [];
    const rightHubs: Asset[] = [];

    for (const hub of hubAssets) {
      const hId = String(hub.id);
      if (leftHubs.length === 0) {
        leftHubs.push(hub);
      } else if (
        leftHubs.length < 2 &&
        (areConnected(hId, String(leftHubs[0].id)) || rightHubs.length >= 2)
      ) {
        leftHubs.push(hub);
      } else if (rightHubs.length < 2) {
        rightHubs.push(hub);
      } else {
        leftHubs.push(hub);
      }
    }

    leftHubs.forEach((h, i) => {
      const slot = leftHubSlots[i] || { x: 225, y: 190 };
      nodeCoords.set(String(h.id), { x: slot.x, y: slot.y, tier: 'hub' });
    });

    rightHubs.forEach((h, i) => {
      const slot = rightHubSlots[i] || { x: 495, y: 190 };
      nodeCoords.set(String(h.id), { x: slot.x, y: slot.y, tier: 'hub' });
    });

    // 3. Camada Externa (Periféricos distribuídos na mesma asa do Sub-Hub ao qual se conectam)
    const leafAssets = rankedAssets.slice(5);
    const leftLeaves: { asset: Asset; prefY: number }[] = [];
    const rightLeaves: { asset: Asset; prefY: number }[] = [];

    for (const leaf of leafAssets) {
      const lId = String(leaf.id);
      const neighbors = Array.from(neighborMap.get(lId) || []);
      let sumX = 0;
      let sumY = 0;
      let count = 0;

      for (const nId of neighbors) {
        const pos = nodeCoords.get(nId);
        if (pos) {
          sumX += pos.x;
          sumY += pos.y;
          count++;
        }
      }

      const avgX = count > 0 ? sumX / count : centerX;
      const avgY = count > 0 ? sumY / count : centerY;

      if (avgX < centerX - 10) {
        leftLeaves.push({ asset: leaf, prefY: avgY });
      } else if (avgX > centerX + 10) {
        rightLeaves.push({ asset: leaf, prefY: avgY });
      } else {
        if (leftLeaves.length <= rightLeaves.length) {
          leftLeaves.push({ asset: leaf, prefY: avgY });
        } else {
          rightLeaves.push({ asset: leaf, prefY: avgY });
        }
      }
    }

    // Ordena verticalmente cada asa pela posição Y do hub conectado para evitar cruzamento de linhas
    leftLeaves.sort((a, b) => a.prefY - b.prefY);
    rightLeaves.sort((a, b) => a.prefY - b.prefY);

    const assignWingCoords = (
      wingList: { asset: Asset; prefY: number }[],
      side: 'left' | 'right'
    ) => {
      const total = wingList.length;
      wingList.forEach((item, idx) => {
        const minY = total === 1 ? 190 : 75;
        const maxY = total === 1 ? 190 : 305;
        const y =
          total === 1
            ? centerY
            : Math.round(minY + (idx * (maxY - minY)) / (total - 1));
        // Leve curvatura em arco nas asas externas (estilo camadas de rede neural)
        const archOffset = Math.sin(((idx + 0.5) / Math.max(total, 1)) * Math.PI) * 22;
        const x =
          side === 'left'
            ? Math.round(105 - archOffset)
            : Math.round(615 + archOffset);

        nodeCoords.set(String(item.asset.id), { x, y, tier: 'leaf' });
      });
    };

    assignWingCoords(leftLeaves, 'left');
    assignWingCoords(rightLeaves, 'right');
  }

  const nodes: GraphNode[] = rankedAssets.map((asset) => {
    const pos = nodeCoords.get(String(asset.id)) || {
      x: centerX,
      y: centerY,
      tier: 'leaf',
    };

  });

  const assetRiskMap = new Map<string, number>(

  );

  const seenConnIds = new Set<string>();
  const links: GraphLink[] = [];
  for (const asset of assets) {
    for (const conn of asset.conexoes || []) {
      const connKey = String(conn.id || `${conn.origemId}-${conn.destinoId}`);
      if (seenConnIds.has(connKey)) continue;
      seenConnIds.add(connKey);
      if (conn.status === 'Bloqueada') continue;

      const dstId = String(conn.destinoId);
      const srcRisk = assetRiskMap.get(srcId) ?? 0;
      const dstRisk = assetRiskMap.get(dstId) ?? 0;
      const weight = Number(conn.pesoPropagacao ?? 0.1);

      });
    }
  }

  const filteredNodes = nodes.filter(
    (n) =>

  );

  const getNodeColor = (risk: number) => {
    if (risk >= 9.0)
      return {

        glow: 'rgba(239, 68, 68, 0.7)',

      };
    if (risk >= 7.0)
      return {
        fill: '#7c2d12',
        stroke: '#f97316',
        glow: 'rgba(249, 115, 22, 0.65)',
        text: '#fdba74',
      };
    if (risk >= 4.0)
      return {
        fill: '#14532d',
        stroke: '#10b981',
        glow: 'rgba(16, 185, 129, 0.5)',
        text: '#86efac',
      };
    return {
      fill: '#0c4a6e',
      stroke: '#0284c7',
      glow: 'rgba(56, 189, 248, 0.4)',
      text: '#7dd3fc',
    };
  };

  const handleNodeClick = (nodeId: string) => {
    setHighlightedNode(nodeId);
    const asset = assets.find((a) => String(a.id) === String(nodeId));
    if (asset) {
      onSelectAsset(asset);
    }
  };

  return (
    <div className="relative flex flex-col h-full bg-[#070b13] border border-slate-800 rounded-xl overflow-hidden shadow-lg">
      <div className="flex flex-wrap items-center justify-between gap-3 px-5 py-3.5 border-b border-slate-800/80 bg-[#090e1a]">
        <div>
          <h2 className="text-sm font-bold text-white tracking-wide flex items-center gap-2">
            <span className="w-2 h-2 rounded-full bg-rose-500 shadow-[0_0_8px_#ef4444]"></span>
            Topologia de Rede Interativa (Mapa de Propagação de Risco)
          </h2>
          <p className="text-xs text-slate-400 font-mono">
            Vulnerabilidades ativas gerando vetor de infecção propagada
          </p>
        </div>

        <div className="flex items-center gap-2">
          <input
            type="text"
            placeholder="Filtrar nós do grafo..."
            value={searchQuery}
            onChange={(e) => setSearchQuery(e.target.value)}
            className="px-2.5 py-1 text-xs bg-[#05080f] border border-slate-700 rounded-md font-mono text-slate-200 placeholder-slate-500 focus:outline-none focus:border-rose-500"
          />

          <div className="flex items-center border border-slate-700 rounded-md bg-[#05080f] overflow-hidden">

            const bendSign = sNode.y <= tNode.y ? 1 : -1;
            const bendAmount = Math.min(dist * 0.1, 18) * bendSign;
            const cx = (sNode.x + tNode.x) / 2 + nx * bendAmount;
            const cy = (sNode.y + tNode.y) / 2 + ny * bendAmount;
            const forwardPath = `M${sNode.x},${sNode.y} Q${cx},${cy} ${tNode.x},${tNode.y}`;
            const reversePath = `M${tNode.x},${tNode.y} Q${cx},${cy} ${sNode.x},${sNode.y}`;

                    y="2.5"

                    className="tabular-nums"
                  >
                    {link.weight.toFixed(2)} {dirSymbol}
                  </text>
                </g>
              </g>
            );

          {filteredNodes.map((node) => {

apiClient.interceptors.response.use(
  (response) => {

  async (error) => {
    const originalRequest = error.config;
    const isAuthEndpoint = originalRequest?.url?.includes('token/');

    if (error.response?.status === 401 && originalRequest && !originalRequest._retry && !isAuthEndpoint) {
      originalRequest._retry = true;

      try {
        if (!refreshTokenPromise) {
          const storedRefreshToken = localStorage.getItem('refreshToken');
          if (!storedRefreshToken) throw new Error('No refresh token found');

          const baseUrl = apiClient.defaults.baseURL || API_BASE_URL;
          const normalizedBase = baseUrl.endsWith('/') ? baseUrl : `${baseUrl}/`;

          refreshTokenPromise = axios
            .post<{ access: string }>(`${normalizedBase}token/refresh/`, {
              refresh: storedRefreshToken,
            })
            .then((res) => {
              const newAccessToken = res.data.access;
              localStorage.setItem('accessToken', newAccessToken);
              return newAccessToken;
            })
            .finally(() => {
              refreshTokenPromise = null;
            });
        }

        const newAccessToken = await refreshTokenPromise;
        originalRequest.headers['Authorization'] = `Bearer ${newAccessToken}`;

        return apiClient(originalRequest);
      } catch (refreshError) {
        localStorage.removeItem('accessToken');
        localStorage.removeItem('refreshToken');
        if (window.location.pathname !== '/login') {
          window.location.href = '/login';
        }
        return Promise.reject(refreshError);
      }
    }

    return Promise.reject(error);
  }

import requests
from inventario.models import Vulnerabilidade


class CVEService:
    def _extrair_metricas_nvd(self, item_cve: dict) -> tuple[float, str, str]:
        """Extrai baseScore, severidade e attackVector suportando CVSS v3.1, v3.0 e v2.0."""
        metrics = item_cve.get("metrics", {})
        for chave in ("cvssMetricV31", "cvssMetricV30"):
            lista = metrics.get(chave)
            if lista and isinstance(lista, list):
                cvss_data = lista[0].get("cvssData", {})
                score = float(cvss_data.get("baseScore", 0.0))
                sev = str(cvss_data.get("baseSeverity", "Medium")).capitalize()
                vetor = str(cvss_data.get("attackVector", "Network / Unauthenticated"))
                return score, sev, vetor

        lista_v2 = metrics.get("cvssMetricV2")
        if lista_v2 and isinstance(lista_v2, list):
            cvss_data = lista_v2[0].get("cvssData", {})
            score = float(cvss_data.get("baseScore", 0.0))
            sev_raw = lista_v2[0].get("baseSeverity") or ("High" if score >= 7.0 else "Medium")
            sev = str(sev_raw).capitalize()
            vetor = str(cvss_data.get("accessVector", "Network / Unauthenticated"))
            return score, sev, vetor

        return 0.0, "Medium", "Network / Unauthenticated"

    def buscar_e_salvar_cve(self, cve_id, dados_fallback=None):
        if not cve_id:
            return None

        cve_id = str(cve_id).strip().upper()
        dados_fallback = dados_fallback or {}
        modo = str(dados_fallback.get("modo", "")).lower()

        # Se o usuário escolheu explicitamente "Cadastro Manual", salva direto com os dados manuais
        if modo == "manual":
            vuln, _ = Vulnerabilidade.objects.update_or_create(
                cve_code=cve_id,
                defaults={
                    "descricao": dados_fallback.get("descricao") or "Vulnerabilidade registrada manualmente.",
                    "categoria": "Cibersegurança",
                    "severidade": dados_fallback.get("severidade", "High"),
                    "status": "Ativa" if dados_fallback.get("status") in (None, "", "Ativo", "Ativa") else dados_fallback.get("status"),
                    "score": float(dados_fallback.get("cvss", 0.0)),
                    "vetor_ataque": dados_fallback.get("vetor_ataque") or dados_fallback.get("vetorAtaque") or "Network / Unauthenticated",
                    "data_descoberta": dados_fallback.get("data_descoberta") or dados_fallback.get("dataDescoberta") or "",
                },
            )
            return vuln

        url = f"https://services.nvd.nist.gov/rest/json/cves/2.0?cveId={cve_id}"

        try:
            response = requests.get(url, timeout=6)
            if response.status_code == 200:
                dados = response.json()

                if dados.get("vulnerabilities"):
                    item = dados["vulnerabilities"][0]["cve"]
                    descriptions = item.get("descriptions", [])
                    descricao = descriptions[0]["value"] if descriptions else f"Vulnerabilidade oficial {cve_id}"
                    publicado = item.get("published", "")[:10]

                    score, severidade, vetor_ataque = self._extrair_metricas_nvd(item)

                    vuln, criada = Vulnerabilidade.objects.get_or_create(
                        cve_code=cve_id,
                        defaults={
                            "descricao": descricao,
                            "categoria": "Cibersegurança",
                            "severidade": severidade,
                            "status": "Ativa",
                            "score": score,
                            "vetor_ataque": vetor_ataque,
                            "data_descoberta": publicado,
                        },
                    )

                    if criada:
                        print(f"✅ Nova falha {cve_id} salva no banco!")
                    else:
                        print(f"ℹ️ A falha {cve_id} já existia no banco.")
                    return vuln
        except Exception as e:
            print(f"Erro ao buscar CVE: {e}")

        # Se o usuário pediu busca exclusiva na API (modo == 'api'), não cria registro falso caso o NIST não encontre
        if modo == "api":
            return None

        # Fallback automático quando há dados manuais enviados junto na requisição
        tem_dados_manuais = any(
            k in dados_fallback for k in ("cvss", "descricao", "severidade", "vetor_ataque", "vetorAtaque")
        )
        if tem_dados_manuais:
            vuln, criada = Vulnerabilidade.objects.get_or_create(
                cve_code=cve_id,
                defaults={
                    "descricao": dados_fallback.get("descricao", "Vulnerabilidade registrada manualmente."),
                    "categoria": "Cibersegurança",
                    "severidade": dados_fallback.get("severidade", "High"),
                    "status": "Ativa" if dados_fallback.get("status") in (None, "", "Ativo", "Ativa") else dados_fallback.get("status"),
                    "score": float(dados_fallback.get("cvss", 0.0)),
                    "vetor_ataque": dados_fallback.get("vetor_ataque") or dados_fallback.get("vetorAtaque") or "Network / Unauthenticated",
                    "data_descoberta": dados_fallback.get("data_descoberta") or dados_fallback.get("dataDescoberta") or "",
                },
            )
            if criada:
                print(f"⚠️ CVE Manual {cve_id} salva via fallback do formulário!")
            return vuln

        return None

import numpy as np
from .models import Equipamento, Factory_equipamento


class MotorMatematico:
    def __init__(self):
        pass

    def calcular_risco_rede(self, usuario=None):
        if usuario is not None and not getattr(usuario, 'is_superuser', False):
            ativos = list(Equipamento.objects.filter(responsavel=usuario))
        else:
            ativos = list(Equipamento.objects.all())

        n = len(ativos)

        if n == 0:
            return None

        matriz_A = np.zeros((n, n))
        vetor_b = np.zeros(n)

        id_para_indice = {ativo.id: indice for indice, ativo in enumerate(ativos)}

        for i, ativo in enumerate(ativos):
            score_total = sum(
                vuln.score
                for vuln in ativo.vulnerabilidades.all()
                if str(vuln.status).lower() not in ('corrigido', 'corrigida')
            )

            expo = Factory_equipamento({'tipo': ativo.tipo}).fator_exposicao()

            risco_proprio = score_total * expo
            vetor_b[i] = risco_proprio

            for conexao in ativo.conexoes_origem.all():
                if conexao.status == 'Bloqueada':
                    continue
                elif conexao.destino.id in id_para_indice:
                    j = id_para_indice[conexao.destino.id]
                    peso = conexao.peso_propagacao
                    if conexao.direcao == 'Bidirecional':
                        matriz_A[i][j] = peso
                        matriz_A[j][i] = peso
                    elif conexao.direcao == 'Inbound':
                        matriz_A[j][i] = peso
                    else:
                        matriz_A[i][j] = peso

        mi = np.eye(n)
        det = np.linalg.det(mi - matriz_A)

        if np.isclose(det, 0):
            print("A matriz não é invertível")
            return None

        solve = np.linalg.solve(mi - matriz_A, vetor_b)

        # Para cada ativo, calcula o maior peso de propagação envolvendo ele (linha ou coluna)
        for i, ativo in enumerate(ativos):
            ativo.risco_proprio = round(float(vetor_b[i]), 2)
            ativo.risco_final = round(float(solve[i]), 2)
            pesos_associados = np.concatenate([matriz_A[i], matriz_A[:, i]])
            ativo.peso_propagacao = round(
                float(np.max(pesos_associados)) if np.any(pesos_associados > 0) else 0.0,
                2,
            )
            ativo.save()

        return True

class ResponsavelField(serializers.Field):
    def to_representation(self, value):
        return value.username if value else ''

    def to_internal_value(self, data):
        if data is None or str(data).strip() == '':
            return None
        valor = str(data).strip()
        usuario = User.objects.filter(username__iexact=valor).first()
        if not usuario and valor.isdigit():
            usuario = User.objects.filter(pk=int(valor)).first()
        if not usuario:
            raise serializers.ValidationError(f"Usuário '{valor}' não encontrado.")
        return usuario

class ConexaoRedeSerializer(serializers.ModelSerializer):

    origem_id = serializers.CharField(source='origem.id', read_only=True)

    class Meta:

class EquipamentoSerializers(serializers.ModelSerializer):
    id = serializers.CharField(read_only=True)
    responsavel = ResponsavelField(required=False, allow_null=True)
    fator_exposicao = serializers.SerializerMethodField()
    cves = VulnerabilidadeSerializers(source='vulnerabilidades', many=True, read_only=True)
    conexoes = serializers.SerializerMethodField()

    class Meta:
        model = Equipamento
        fields = '__all__'

    def create(self, validated_data):
        vulnerabilidades = validated_data.pop('vulnerabilidades', [])
        instancia = Factory_equipamento(validated_data)
        instancia.save()
        if vulnerabilidades:
            instancia.vulnerabilidades.set(vulnerabilidades)
        return instancia

    def get_fator_exposicao(self, obj):
        return Factory_equipamento({'tipo': obj.tipo}).fator_exposicao()

    def to_representation(self, instance):
        ret = super().to_representation(instance)
        if ret.get('responsavel') is None:
            ret['responsavel'] = ''
        return ret

    def get_conexoes(self, obj):
        conexoes_qs = ConexaoRede.objects.filter(Q(origem=obj) | Q(destino=obj))
        resultado = []
        for conn in conexoes_qs:
            if conn.origem_id == obj.id:
                resultado.append({
                    'id': str(conn.id),
                    'origem_id': str(conn.origem_id),
                    'destino_id': str(conn.destino_id),
                    'destino_nome': conn.destino.nome,
                    'porta': conn.porta,
                    'protocolo': conn.protocolo,
                    'peso_propagacao': conn.peso_propagacao,
                    'direcao': conn.direcao,
                    'status': conn.status,
                })
            else:
                direcao_inversa = (
                    'Inbound' if conn.direcao == 'Outbound'
                    else 'Outbound' if conn.direcao == 'Inbound'
                    else 'Bidirecional'
                )
                resultado.append({
                    'id': str(conn.id),
                    'origem_id': str(obj.id),
                    'destino_id': str(conn.origem_id),
                    'destino_nome': conn.origem.nome,
                    'porta': conn.porta,
                    'protocolo': conn.protocolo,
                    'peso_propagacao': conn.peso_propagacao,
                    'direcao': direcao_inversa,
                    'status': conn.status,
                })
        return resultado

def obter_equipamentos_do_usuario(user):
    if user.is_superuser:
        return Equipamento.objects.all()
    return Equipamento.objects.filter(responsavel=user)


def inverter_direcao(direcao: str) -> str:
    if direcao == 'Outbound':
        return 'Inbound'
    if direcao == 'Inbound':
        return 'Outbound'
    return 'Bidirecional'

class AdicionarConexaoAPI(APIView):
    permission_classes = [IsAuthenticated]

    def post(self, request, pk):
        try:
            origem = obter_equipamentos_do_usuario(request.user).get(pk=pk)
            destino_id = request.data.get('destino_id')
            destino = Equipamento.objects.get(pk=destino_id)

            peso = request.data.get('peso_propagacao', 0.1)
            porta = request.data.get('porta', 443)
            protocolo = request.data.get('protocolo', 'HTTPS')
            direcao = request.data.get('direcao', 'Bidirecional')
            status_conn = request.data.get('status', 'Ativa')

            with transaction.atomic():
                # Verifica se já existe a conexão cadastrada no sentido inverso (destino -> origem)
                conexao_inversa = ConexaoRede.objects.filter(origem=destino, destino=origem).first()
                if conexao_inversa:
                    conexao_inversa.peso_propagacao = peso
                    conexao_inversa.porta = porta
                    conexao_inversa.protocolo = protocolo
                    conexao_inversa.direcao = inverter_direcao(direcao)
                    conexao_inversa.status = status_conn
                    conexao_inversa.save()
                else:
                    ConexaoRede.objects.update_or_create(
                        origem=origem,
                        destino=destino,
                        defaults={
                            'peso_propagacao': peso,
                            'porta': porta,
                            'protocolo': protocolo,
                            'direcao': direcao,
                            'status': status_conn,
                        }
                    )

                motor = MotorMatematico()
                if motor.calcular_risco_rede() is None:
                    transaction.set_rollback(True)
                    return Response(
                        {"erro": "Matriz de dependências não invertível"},
                        status=status.HTTP_400_BAD_REQUEST,
                    )

            origem.refresh_from_db()

            serializer = EquipamentoSerializers(origem)
            return Response(serializer.data, status=status.HTTP_201_CREATED)

        except Equipamento.DoesNotExist:
            return Response({"erro": "Ativo não encontrado"}, status=status.HTTP_404_NOT_FOUND)
        except Exception as e:
            return Response({"erro": str(e)}, status=status.HTTP_400_BAD_REQUEST)


class AdicionarCveAPI(APIView):
    permission_classes = [IsAuthenticated]

    def post(self, request, pk):

                origem.refresh_from_db()

                serializer = EquipamentoSerializers(origem)
                return Response(serializer.data, status=status.HTTP_201_CREATED)

            else:
                return Response({"erro": "CVE não encontrada na base do NIST"}, status=status.HTTP_404_NOT_FOUND)

        except Equipamento.DoesNotExist:
            return Response({"erro": "Ativo não encontrado"}, status=status.HTTP_404_NOT_FOUND)
        except Exception as e:
            return Response({"erro": str(e)}, status=status.HTTP_400_BAD_REQUEST)


class DashboardMetricsAPI(APIView):

    def get(self, request):

                "eigenvector_centrality": {
                    "matrix_a": [], "vector_x": [], "density": 0.0, "metrics_count": 0
                }
            })

        matriz_A = np.zeros((n, n))
        id_para_indice = {ativo.id: indice for indice, ativo in enumerate(ativos)}

        num_conexoes = 0
        for i, ativo in enumerate(ativos):
            for conexao in ativo.conexoes_origem.all():
                if conexao.status == 'Bloqueada':
                    continue
                elif conexao.destino.id in id_para_indice:
                    j = id_para_indice[conexao.destino.id]
                    peso = conexao.peso_propagacao
                    if conexao.direcao == 'Bidirecional':
                        matriz_A[i][j] = peso
                        matriz_A[j][i] = peso
                    elif conexao.direcao == 'Inbound':
                        matriz_A[j][i] = peso
                    else:
                        matriz_A[i][j] = peso
        num_conexoes = int(np.count_nonzero(matriz_A))
        densidade = num_conexoes / (n * n) if n > 0 else 0

        try:
            autovalores = np.linalg.eigvals(matriz_A)
            lambda_max = max(abs(autovalores))
        except Exception:
            lambda_max = 0.0

        vetor_x = [ativo.risco_final for ativo in ativos]
        nomes_ativos = [ativo.nome for ativo in ativos]

        cves_ativas = (
            Vulnerabilidade.objects.filter(equipamento__in=ativos_qs)
            .exclude(status__iexact='Corrigido')
            .distinct()
            .count()
        )

        dados = {
            "total_assets": n,
            "lambda_max": float(lambda_max),
            "unpatched_cves": cves_ativas,
            "matrix_density": float(densidade),
            "propagation_speed": 0.85,
            "heatmap": {
                "labels": nomes_ativos,
                "matrix": matriz_A.tolist()
            },
            "eigenvector_centrality": {
                "matrix_a": matriz_A.tolist(),
                "vector_x": vetor_x,
                "density": float(densidade),
                "metrics_count": n
            }
        }

        return Response(dados, status=status.HTTP_200_OK)


class RemoverConexaoAPI(APIView):
    permission_classes = [IsAuthenticated]

    def patch(self, request, pk, conexao_id):
        try:
            ativo_atual = obter_equipamentos_do_usuario(request.user).get(pk=pk)
            with transaction.atomic():
                conexao = ConexaoRede.objects.get(id=conexao_id)
                conexao.porta = request.data.get('porta', conexao.porta)
                conexao.protocolo = request.data.get('protocolo', conexao.protocolo)
                conexao.peso_propagacao = request.data.get('peso_propagacao', conexao.peso_propagacao)

                nova_direcao = request.data.get('direcao')
                if nova_direcao:
                    # Se o usuário está editando a conexão a partir da tela do ativo de destino,
                    # desfazemos a inversão de perspectiva antes de gravar no banco!
                    if conexao.destino_id == ativo_atual.id and conexao.origem_id != ativo_atual.id:
                        conexao.direcao = inverter_direcao(nova_direcao)
                    else:
                        conexao.direcao = nova_direcao

                conexao.status = request.data.get('status', conexao.status)
                conexao.save()

                if MotorMatematico().calcular_risco_rede() is None:
                    transaction.set_rollback(True)
                    return Response(
                        {"erro": "Matriz de dependências não invertível"},
                        status=status.HTTP_400_BAD_REQUEST,
                    )

            return Response(status=status.HTTP_200_OK)
        except Equipamento.DoesNotExist:
            return Response({"erro": "Ativo não encontrado"}, status=status.HTTP_404_NOT_FOUND)
        except ConexaoRede.DoesNotExist:
            return Response({"erro": "Conexão não encontrada"}, status=status.HTTP_404_NOT_FOUND)
        except Exception as e:
            return Response({"erro": str(e)}, status=status.HTTP_400_BAD_REQUEST)

    def delete(self, request, pk, conexao_id):
        try:
            obter_equipamentos_do_usuario(request.user).get(pk=pk)
            conexao = ConexaoRede.objects.get(id=conexao_id)
            conexao.delete()

            motor = MotorMatematico()
            motor.calcular_risco_rede()

            return Response(status=status.HTTP_204_NO_CONTENT)

        except Equipamento.DoesNotExist:
            return Response({"erro": "Ativo não encontrado"}, status=status.HTTP_404_NOT_FOUND)
        except ConexaoRede.DoesNotExist:
            return Response({"erro": "Conexão não encontrada"}, status=status.HTTP_404_NOT_FOUND)

class TestarPingAPI(APIView):
    permission_classes = [IsAuthenticated]

    def post(self, request, pk):
        try:
            ativo = obter_equipamentos_do_usuario(request.user).get(pk=pk)
            portas = list(
                ConexaoRede.objects.filter(Q(origem=ativo) | Q(destino=ativo))
                .exclude(status='Bloqueada')
                .values_list('porta', flat=True)
                .distinct()
            )
            if not portas:
                portas = [22, 80, 443]
            return Response({
                "success": True,
                "latency_ms": 6,
                "open_ports": sorted(portas)
            }, status=status.HTTP_200_OK)
        except Equipamento.DoesNotExist:
            return Response({"erro": "Ativo não encontrado"}, status=status.HTTP_404_NOT_FOUND)
